# BlogSphere — Full-Stack Blogging Platform

BlogSphere is a web-based blogging platform developed to provide users with a place to create, publish, and explore blog content. The project was built to gain practical experience in full-stack web development, frontend design, backend development, and database integration.

## Overview

BlogSphere combines a frontend interface with a backend application and database to support blogging functionality. The project is also an opportunity to explore AI-assisted software development and improve code quality through testing, debugging, and iterative development.

## Tech Stack

- **Frontend:** React
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Development Tools:** Git, GitHub, Visual Studio Code
- **AI-Assisted Development:** ChatGPT

## Features

The project is designed around blogging functionality, including:

- User-facing web interface
- Blog post creation and content management
- User-related functionality
- Backend API integration
- Database-backed application data

*Note: The exact features and their current implementation status will be documented as the project is reviewed and improved.*

## Project Structure

The application is organised into frontend and backend components. The exact directory structure may vary depending on the current implementation.

- **Frontend:** User interface and client-side functionality
- **Backend:** Server-side logic and API handling
- **Database:** Data persistence using MongoDB

## Getting Started

### Prerequisites

Before running the project, ensure that the following are available:

- Node.js and npm
- MongoDB or a configured MongoDB connection
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Kanchana1125/BlogSphere.git
   ```

2. Navigate into the project directory:

   ```bash
   cd BlogSphere
   ```

3. Install dependencies in the relevant frontend and backend directories using `npm install`.

4. Configure the required environment variables based on the application's existing configuration.

5. Start the frontend and backend using the scripts defined in their respective `package.json` files.

**Note:** The exact commands and environment variables should be confirmed against the current project files before use.
